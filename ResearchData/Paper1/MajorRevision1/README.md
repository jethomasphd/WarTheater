# Paper 1 — Major Revision 1

**Reciprocity Without a Lag: Same-Day Coupling and Regime-Contingent Escalation in the 2026
US–Iran War.** A self-contained, fully reproducible revision of
[Paper 1](../README.md), built around the five statistics the co-author asked the paper to be
written towards, with the directional claims scoped as the memo requested and a placebo check
added on the break dates.

> **Argument.** Strikes and retaliation moved together within the day, not across days
> (r = 0.69 in combat; zero-lag VAR; no Granger causality); the coupling switched on in
> combat, off in the ceasefire, and on again at the resumption (0.69 / 0.18 / 0.66;
> Fisher z p = 0.0007); which side set the tempo cannot be identified from daily data
> (the variance decomposition reverses with the ordering, 41/2 vs 44/0.2); the balance of the
> exchange flipped (0.68 → 1.42) and retaliation's reach saturated at 13 countries by Day 22;
> and diplomacy tracked the regime, not the week (weekly r = 0.06).

## Deliverable

`manuscript/Paper1_MajorRevision1.docx` — the Word manuscript (broadly APA 7). Sections 1
(Introduction) and 6 (Discussion) are drafted as bullet points for the co-author to write by
hand; Sections 2–5 and 7 (data, methods, results, robustness, limitations) are complete and
carry the numbers. The markdown source is `manuscript/paper1_major_revision1.md`.

## Reproduce everything (about three minutes)

```bash
cd ResearchData/Paper1/MajorRevision1
python3 -m pip install -r requirements.txt   # pandas, numpy, scipy, statsmodels, matplotlib
bash run_all.sh                              # panel + every table + every figure + verification (+ .docx if Node is present)
```

To rebuild only the Word manuscript:

```bash
cd manuscript && npm install && node make_docx.js     # needs Node.js; installs the pinned `docx` package
```

The analysis is pinned to the frozen `../../releases/v1.2/iranwar_event_dataset.csv`; its MD5
is verified before anything runs. Every stochastic step is seeded (`SEED = 42`). The last
analysis step re-derives every headline number, asserts it against the manuscript, and checks
that each appears verbatim in the text; the Word build then injects every table from the
regenerated CSVs and compares each cell with the markdown table. Upstream drift fails loudly.

## The five statistics (all regenerated by `run_all.sh`)

| # | Finding | Evidence |
|---|---|---|
| 1 | Reciprocity is **same-day, not lagged** | combat same-day r = 0.69 (0.48–0.82); AIC/BIC/HQIC/FPE all select lag 0; Granger p = 0.78 / 0.44; IRF band includes zero from day 1 (`t02_*`, Fig. 2, Fig. A1) |
| 2 | The coupling **switches with the regime** | r = 0.69 (combat) → 0.18 (ceasefire, n.s.) → 0.66 (resumption); Fisher z p = 0.0007, Holm 0.002 (`t03_*`, Fig. 3) |
| 3 | **Who set the tempo is not identified** | FEVD 41% vs 2% (strikes first) becomes 0.2% vs 44% (retaliation first); ρ² = 0.38 (`t04_*`, Fig. 4) |
| 4 | **Balance flipped; reach saturated** | ratio 0.68 (0.59–0.77) → 1.42 (0.94–2.32); 13 countries by Day 22, none in the next 148 days (`t05_*`, Fig. 5) |
| 5 | **Diplomacy tracks the regime** | weekly r = 0.06 (n.s.); 3.2 → 0.4 events/day at the resumption; Kruskal–Wallis p < 0.001 (`t06_*`, Fig. 6) |

Supporting: regimes recovered within 1, 1, 6 days; placebo p = 0.001 against three nulls, with
the caveat that the BIC segment count alone is not evidence (`t07_*`, Fig. 7); directional
claims scoped — resumption p = 0.026 on 22 observations (null under raw rows), regime-demeaned
full-sample p from 0.0009 to 0.26 (`t08_*`).

## Relationship to the parent paper

Same frozen data, same panel (asserted identical), same estimators, same point estimates. What
is new: the organisation around five statistics, the scoping of directional claims, the
placebo and sensitivity checks on the break dates, the regime-demeaned re-estimation, the
corrected impulse-response band, Holm-adjusted Fisher comparisons, bootstrap intervals for the
ratio, a regime-level diplomacy test, and the APA Word manuscript. See `REVISION_NOTES.md`.
