# Paper 1 — Reciprocity Without a Lag

**Contemporaneous coupling and regime-contingent escalation in the 2026 US–Iran War.**

A complete, self-contained, fully reproducible political-science study built on the
[IranWar.ai Event-Level Research Dataset](../) v1.2 (Days 1–170). It tests classical theories
of escalation and reciprocity — the conflict spiral, the escalation ladder, tit-for-tat, and
Schelling's compellence/punishment distinction — against 170 days of daily strike and
retaliation tempo.

> **Thesis.** Escalation in this war was reciprocal but *contemporaneous, not lagged*; the
> reciprocal coupling *switched on and off with the political regime* (strong in combat,
> statistically absent in the ceasefire, back at the resumption); the July re-escalation was
> *reactive* (retaliation led strikes); and Iran's declining relative response traces
> *capability depletion*. "Who set the tempo" in open combat is *under-identified* at daily
> resolution — a methodological result in its own right.

## Reproduce everything (~1 minute)

```bash
cd ResearchData/Paper1
python3 -m pip install -r requirements.txt   # pandas, numpy, scipy, statsmodels, matplotlib
bash run_all.sh                              # regenerates panel + all tables + all figures
```

The analysis is **pinned to the frozen** `../releases/v1.2/iranwar_event_dataset.csv`, so it
reproduces identically regardless of later dataset releases. Monte-Carlo error bands are seeded
(`SEED=42`); there is no network or wall-clock dependence. Point it at a different dataset with
`IRANWAR_DATASET=/path/to.csv bash run_all.sh`.

## Headline findings (all regenerated by `run_all.sh`)

| # | Finding | Evidence |
|---|---|---|
| 1 | Reciprocity is **contemporaneous, not lagged** | combat same-day r = 0.69, full-sample r = 0.83; AIC/BIC/HQIC/FPE all select lag 0 in combat; no daily-lag Granger causality (`t03_*`) |
| 2 | Coupling is **regime-contingent** | combat r = 0.69 → ceasefire r = 0.18 (n.s.) → resumption r = 0.66; Fisher z p = 0.0007 (`t05_*`, fig5) |
| 3 | Re-escalation was **reactive** (retaliation → strikes) | full-sample Granger retal→strikes F = 4.05, p = 0.0001; resumption p = 0.03; lead-lag 0.45 vs −0.06 (`t05_*`) |
| 4 | **Asymmetry / depletion** | strike:retal ratio 0.68 → 1.42 across regimes; retaliation saturates at 13 countries by Day 22 (`t01`, fig2) |
| 5 | Regimes are **endogenously recovered** | BIC-optimal breaks at Days 40/131/147 match documented 41/130/153 within 1–6 days (`t04_*`, fig4) |
| 6 | "Who set the tempo" is **under-identified** | combat FEVD asymmetry flips entirely under Cholesky re-ordering (`t03_fevd.csv`) |
| 7 | Diplomacy runs on a **parallel track** | talking-while-fighting (2.6–3.2/day) then collapses at resumption; daily/weekly decoupled (weekly r = 0.06, n.s.) (`t07_*`, fig6) |
| 8 | Casualty tempo caveat | daily killed does **not** track daily strike/retaliation tempo — do not use tempo as a lethality proxy (`t06_casualty_propagation.csv`) |

Read the full argument in [`manuscript/paper1_reciprocity_regime.md`](manuscript/paper1_reciprocity_regime.md).

## Scope & limitations

This is a rigorous within-case study of one conflict from OSINT data. Findings are hypotheses
for comparative testing, not established generalizations, and they inherit the dataset's
documented limitations (reporting bias, contested casualties, the strike target-explosion). See
`manuscript/…` §9 and `docs/METHODS.md` §10. The study rests **no** argument on casualty tempo
or on ordering-dependent (contemporaneous) directional claims.
